Projeto Cemiterio

IDE's utilizadas: Visual Studio Code, Intelijj.

Funcionalidades
--Usuários (User)
Cadastro de usuários do sistema (ex: administradores)

Listagem, edição e exclusão de contas

--Setores (Sector)
Cadastro de setores do cemitério (ex: quadras, áreas)

Edição e visualização de informações dos setores

Exclusão de setores

-Falecidos (DeadUser)
Cadastro de falecidos (nome, datas, setor, localização)

Associação com setor e número do jazigo

Edição e remoção de registros

--Tecnologias Utilizadas

Java 17

Spring Boot

Spring Data JPA

H2 / PostgreSQL

HTML5 + CSS3 

Lombok

Thymeleaf

--Futuras Melhorias

Controle de acesso baseado em permissões

Upload de documentos ou imagens dos registros

Geolocalização dos túmulos

Exportação de dados (PDF, Excel)

Notificações e lembretes de manutenção
